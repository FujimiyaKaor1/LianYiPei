# 服务目录说明

这个目录处于过渡状态，包含两类文件：

- 基础设施服务：例如调度器、邮件、外部数据、图谱、模型客户端、日志和数据迁移。这些服务暂未按业务领域迁移。
- 旧路径兼容层：文件顶部有 `[兼容层]` 标记，实际实现位于 `app/applications/`。它们保留旧导入路径，避免历史测试和脚本立即失效。

修改规则：

- 看到 `[兼容层]` 时，编辑它指向的 `app/applications/<domain>/services/` 文件。
- 新的业务服务不要继续直接添加到这里；先选择 `enterprise`、`fulfillment`、`matching` 或 `risk` 领域。
- 基础设施服务如果被多个领域共享，可以暂时留在这里，并在文件名和模块说明中写清职责。

兼容层全部迁完并完成引用替换后，才可以逐步移除旧文件；当前不能因为文件内容很短就删除它们。
