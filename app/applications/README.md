# 业务应用层

这里是后端业务服务的主目录。按领域查找代码，不按技术名词在整个仓库中搜索：

| 领域 | 目录 | 主要能力 |
| --- | --- | --- |
| enterprise | `enterprise/services/` | 企业画像、认证、链主、质量标签、数据授权 |
| fulfillment | `fulfillment/services/` | 订单、履约、合同、发票、报价池、协同 |
| matching | `matching/services/` | 供需匹配、意图解析、排序、推荐 |
| risk | `risk/services/` | 信用、预警、告警通知和风险工作流 |

约定：

1. 新增或修改业务逻辑时，优先放到对应领域目录。
2. 路由只负责请求解析、权限和响应编排，业务规则放在领域服务中。
3. `app/services/` 中带“兼容层”标记的文件只用于保留旧导入路径，不在其中复制实现。
