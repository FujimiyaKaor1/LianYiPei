# 天下工厂对标调研与链易配优化方案

更新时间：2026-09-22  研究对象：<https://www.tianxiagongchang.com/>

## 1. 结论摘要

天下工厂的公开产品核心是制造企业目录，而不是品牌官网：用户以产品、工艺、企业名或地区进入，使用条件筛选缩小范围，再进入企业档案和联系动作。链易配当前已经具备更深的业务能力（AI 找厂、询价报价、订单履约、政府与企业工作台），但公开入口此前更偏品牌叙事和 AI 导流，目录检索的即时反馈不够强。

本轮已执行的优化：

- `/search` 的主搜索动作改为直接查询公开目录，保留独立的“AI 找工厂”旁路入口。
- 结果标题增加当前页的结果区间和数据更新时间提示，强化检索反馈与数据边界。
- 保留企业、产品、供应信息、采购需求四类资源，以及地区、城市、行业、经营状态、注册资本、出口、决策人、专精特新、绿色工厂等真实 API 筛选。
- 对标数据的导入和功能增强脚本已存在：`scripts/seed/import_tianxiagongchang_data.py` 与 `scripts/seed/enrich_tianxiagongchang_data.py`，不会把抓取结果伪装成实时事实。

## 3. 差距矩阵

| 维度 | 天下工厂强项 | 链易配现状 | 优先级 | 方案 |
| --- | --- | --- | --- | --- |
| 首屏任务 | 直接进入搜索 | 有 `/aisearch/`、品牌首页和 `/search` 多入口 | P0 | `/search` 以目录检索为主入口，AI 为旁路能力。已执行。 |
| 检索密度 | 企业目录、关键词、地域和行业组合 | API 能力完整，但公开页面先导向 AI | P0 | 主按钮直接请求 `/api/public/search`，展示结果总量、区间、来源。已执行。 |
| 结果比较 | 列表扫描和企业摘要 | 已有列表，但资源类型混排 | P1 | 默认 `enterprise`；产品/供应/采购需求用清晰 tab 切换，避免同页混淆。现有实现已覆盖。 |
| 企业详情 | 工商摘要、经营范围、联系方式转化 | 公开脱敏详情、产品、能力信号和登录后联系 | P0 | 保持匿名脱敏；联系、询价、收藏统一进入登录/授权流程。现有实现已覆盖。 |
| 数据规模 | 搜索结果量大 | 已有 1,000 条外部样本落盘，是否入库取决于部署环境 | P0 | 发布前执行 import + enrich，页面标注来源、更新时间和演示字段。 |
| AI 能力 | 不是目标站主要差异点 | 链易配有自然语言匹配和解释 | P1 | 保持 AI 的差异化，不用 AI 取代关键词检索；从目录结果一键带入需求。 |
| 业务闭环 | 目录到联系 | 链易配可继续询价、报价、订单、履约、风控 | P1 | 详情页 CTA 统一生成询价意图，登录后进入企业工作台，不做假联系方式。 |
| 信任与合规 | 公开工商/经营信息 | 已有数据新鲜度和公开/演示标识 | P0 | 所有合成字段加来源标签；严禁把抓取字段、平台核验、AI 推断混成一个“认证”。 |
| 移动端 | 目录查找适合移动访问 | 已有移动筛选抽屉 | P1 | 继续保持结果优先，移动端筛选抽屉和 sticky 搜索条作为验收项。 |

## 4. 实施路线

### P0：本版本必须可演示

1. 执行 `python3 scripts/seed/import_tianxiagongchang_data.py`，再执行 `python3 scripts/seed/enrich_tianxiagongchang_data.py`；仅追加、不清空现有企业。
2. 验证 `/api/public/home`、`/api/public/search?q=模具&type=enterprise`、`/api/public/enterprises/<id>` 三条匿名接口。
3. 在 `/search` 演示：关键词搜索、地区/行业/状态/资本筛选、快速标签、分页、打开详情、联系/询价登录门禁。
4. 把 `source`、`data_updated_at`、`is_demo`、`synthetic_fields` 作为页面验收字段；未知字段显示“待更新”，不以随机数据冒充事实。

### P1：下一迭代

1. 为结果卡增加“收藏”本地暂存和登录后同步，避免匿名状态误写服务端。
2. 增加检索历史和已选条件 chips，支持一键移除单个条件。
3. 增加企业对比视图：地区、行业、注册资本、公开能力信号、数据更新时间五列并排比较。
4. 从企业详情的“联系/发起询价”直接生成带企业 ID、产品和需求上下文的询价草稿。

### P2：规模化能力

1. 把外部来源同步做成可追溯批次：抓取批次、字段映射、去重、失败行、回滚记录。
2. 增加搜索日志的匿名聚合指标：无结果词、热门地区、详情转化率；不采集第三方追踪数据。
3. 对公开数据做字段级授权：工商公开、企业自填、平台核验、模型推断分别展示。

## 5. 可演示验收清单

- [ ] `/search` 首屏不登录即可搜索。
- [ ] 搜索 `模具` 能返回企业或产品资源，结果总数与分页可见。
- [ ] 切换“工厂 / 产品 / 供应信息 / 采购需求”后 URL 和结果类型同步变化。
- [ ] 地区、城市、行业、经营状态、注册资本和快速筛选会真实影响 API 请求。
- [ ] 打开企业详情只展示公开/脱敏摘要；联系方式和询价需要登录。
- [ ] 详情显示来源、更新时间、演示/生产口径；合成字段不显示为真实核验。
- [ ] `/aia` 能接收从搜索条件生成的自然语言需求，并能继续到匹配链路。
- [ ] 360px 移动宽度下筛选抽屉、搜索按钮、结果标题和 CTA 不溢出。
